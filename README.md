# R Data Analyst Internship - Task 1

## Project Overview
This project focuses on data cleaning, preprocessing, and exploratory data analysis using R.

## Dataset
Titanic Passenger Dataset (891 rows and 12 original columns).

## Technologies Used
- R
- Visual Studio Code
- dplyr
- ggplot2
- tidyr
- corrplot

## Project Structure
- Dataset: Original Titanic dataset
- R_Scripts: Data cleaning and analysis scripts
- Outputs/Graphs: Data visualizations
- Outputs/Results: Cleaned datasets and analysis results
- Report: Final internship report

## Key Activities
1. Missing value treatment
2. Duplicate checking
3. Outlier detection using IQR
4. Min-Max normalization
5. Categorical encoding
6. Exploratory data analysis
7. Correlation analysis
8. Data visualization

## Key Findings
- Dataset contains 891 passenger records.
- Overall survival rate: 38.4%.
- Female survival rate: 74.2%.
- Male survival rate: 18.9%.
- Passenger class and fare show associations with survival.

## How to Run
Run the following scripts in order:

1. R_Scripts/week1_analysis.R
2. R_Scripts/week1_cleaning.R
3. R_Scripts/week1_eda.R
